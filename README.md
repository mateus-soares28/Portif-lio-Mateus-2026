# Portfólio Mateus Soares

Projeto de portfólio pessoal desenvolvido com HTML, CSS e JavaScript. A página apresenta uma interface moderna com fundo animado em WebGL, efeito glassmorphism, alternância entre tema claro e escuro, seção de projetos filtrável e áreas de apresentação profissional.

## Visão geral

O site foi criado para apresentar o trabalho de Mateus Soares como Desenvolvedor Full Stack, reunindo informações de contato, tecnologias utilizadas, projetos em destaque e uma breve trajetória profissional.

## Funcionalidades

- Fundo animado com shader em WebGL.
- Tema claro e escuro com preferência salva no `localStorage`.
- Navegação por âncoras entre início, projetos, sobre e contato.
- Botão de rolagem suave para a seção de projetos.
- Cards de projetos com imagem, descrição, tecnologias e link externo.
- Filtro de projetos por categoria.
- Layout responsivo para desktop, notebook, tablet e mobile.
- Links diretos para WhatsApp, GitHub, LinkedIn e e-mail.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- WebGL
- Google Fonts
- Phosphor Icons

## Como executar

Como o projeto é estático, não é necessário instalar dependências.

1. Clone o repositório:

```bash
git clone <url-do-repositorio>
```

2. Acesse a pasta do projeto:

```bash
cd Projeto-shader-js
```

3. Abra o arquivo `index.html` no navegador.

Também é possível executar com uma extensão como Live Server no VS Code.

## Personalização

Para alterar os dados principais do portfólio, edite o arquivo `index.html`.

- Projetos: atualize os cards dentro da seção `#projetos`.
- Imagens: adicione ou substitua arquivos na pasta `img`.
- Estilos: ajuste cores, espaçamentos e componentes em `css/style.css`.
- Responsividade: altere os pontos de quebra em `css/responsive.css`.
- Interações: edite shader, tema e filtros em `js/script.js`.

## Observações

O projeto utiliza fontes e ícones carregados por CDN. Para visualizar esses recursos corretamente, é necessário estar conectado à internet ao abrir a página.
